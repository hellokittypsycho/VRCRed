Help & setup

Get your stream ready

Follow these steps on the PC running VRChat.

  1. 1
    Install the camera receiverChecking

    Run Setup Camera.cmd once. It needs 64-bit Python 3.12 or 3.13. Viewers only need a browser.

  2. 2
    Connect the in-game cameraChecking

    In VRChat, enable Camera → Stream → Spout Stream. Open this panel’s Settings, choose your audio inputs, then select Start stream.

  3. 3
    Load your avatar controlsChecking

    Enable Action Menu → OSC → Enabled in VRChat. Wear a published avatar, then open Avatar. Use the refresh icon if it is missing. Effects depend on what the avatar supports.

  4. 4
    Invite your friendsChecking

    Save your public HTTPS URL in Settings → Sharing & access. Create an invitation under Manage accounts & invites, then share the URL and invitation code. New members can watch and chat; only admins control the stream.

Watching & chatting

Use the speaker button to hear the stream. Controls fade while you watch—move your pointer or tap to bring them back. Open Chat to join the conversation; Enter sends a message and Shift+Enter adds a new line.

Stream offline? Your host has not started broadcasting yet. If a live stream drops, the player reconnects automatically.

Open your profile to change your password or show the entire camera frame. Your sign-in is saved for up to 30 days.

Something still isn’t working?

Camera setup: run npm run doctor in the project folder to check the installation. For missing Python, install a 64-bit 3.12 or 3.13 version, then run Setup Camera.cmd again.

No avatar reaction: check that OSC is enabled and the selected configuration matches the avatar you are wearing. “Sent” means the packet was sent; “VRChat confirmed” means feedback matched.

Friends cannot open the panel: keep the server and tunnel running, save the exact public HTTPS address, and check the host’s upload speed and tunnel allowance.

Save your data: stop the server and back up the data folder. To reset an admin password, run Reset Admin Password.cmd. Keep the database.
